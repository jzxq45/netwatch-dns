# Правовой и этический скоуп (RU)

Инструмент предназначен для администратора **собственной** сети — например,
домашней сети своей семьи или сети своей организации, где ты имеешь
административные полномочия.

## Что это правоз-Compatible

- Ты администрируешь сеть, которой владеешь или которой управляешь.
- Данные не покидают твой диск (нет отправки наружу каких-либо логов).
- Не читается содержимое HTTPS-трафика — только имена DNS-запросов.
- Не используется против работоспособности сервисов (не блокатор трафика,
  только DNS-политика своей сети).

## Что делается ЗАПРЕЩЁННЫМ. Худший вариант — следить за человеком без его ведома

Ст. 137–138 УК РФ (частная жизнь, тайна связи) и GDPR-аналоги по духу:
- Сбор действий конкретного лица без его информированности и согласия.
- Использование логов для шантажа, давления на решение о работе, развода,
  выяснения личных обстоятельств.
- Публикация логов кому-то третьему, синхронизация в облако чужим сервисом.
- Мониторинг сетей, которыми ты НЕ управляешь (соседи, офис компании, где
  ты не админ, публичные точки доступа).

## Обязательные практики

1. **Уведомить пользователей сети**: все члены семьи / сотрудники должны
   знать, что DNS-запросы сети логируются локально.
2. **Логи — только локально**: `monitor.db` остаётся на мониторе; резервные
   копии не загружать в облачные диски без понимания последствий.
3. **Retention**: строки старше 7 дней (регулируется `retention_days`)
   автоматически удаляются — не храни больше, чем нужно.
4. **web_token**: если панель открыта в LAN (0.0.0.0), используй токен,
   чтобы читать ленту могли только те, кому ты доверяешь.
5. **Не обходить пользовательские ожидания**: если человек попросил не
   «мониторить» его — уважай это, вынь его IP из мониторинга
   (либо исключи адрес по noise-списку / на стороне роутера).

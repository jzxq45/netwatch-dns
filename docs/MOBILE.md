# Mobile: PWA и доступ с телефона

## Доступ с телефона

1. `web_listen: 0.0.0.0:8080` в monitor.yaml (по умолчанию панель слушает
   только 127.0.0.1).
2. Разрешить входящий TCP 8080 в firewall хоста:
   ```
   netsh advfirewall firewall add rule name="netwatch web" dir=in action=allow protocol=tcp localport=8080
   ```
3. На телефоне: `http://<IP-монитора>:8080`.

Используй `web_token` если в сети есть чужие устройства (см. monitor.yaml.example).

## PWA: добавить на главный экран

- **Android / Chrome**: ⋮ → «Добавить на главный экран» → подтвердить.
  Иконка откроет панель без адресной строки.
- **iOS / Safari**: Поделиться → «На экран «Домой»».

## Ограничения без HTTPS

Service Worker (кэш, offline, web-push) активируется ТОЛЬКО на HTTPS
или на `localhost`. Работая по HTTP внутри LAN:
- нет offline-кэша (meta-refresh 5 с живёт не в фоне);
- ярлык на главном экране устанавливается как обычная ссылка, без SW.

Данные всё равно живут на сервере, так что при потере сети ничего не теряется.

## Варианты получить HTTPS (понадобится для полного PWA)

1. **Tailscale** (рекомендуется): сеть mesh с TLS-сертификатами MagicDNS
   на хосте; панель `https://monitor.example.ts.net:8080`; телефон ставит
   клиент Tailscale. Приятный бонус — работает ВНЕ дома.
2. **Self-signed CA**: сгенерировать CA, добавить его в хранилище телефона;
   ломает удобство и лишний раз требует ручных действий. Для домашнего
   случая первая из них проще; это не провокация протокольных ограничений
   приложения (нет CA на клиенте = нет MITM по замыслу проекта).
